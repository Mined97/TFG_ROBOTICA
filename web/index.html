Notas de conexión

⚠️ Arduino UNO usa lógica de 5 V y ESP32 3,3 V. Protege RX del ESP32 con adaptador de nivel o divisor resistivo.
🔌 UART entre placas: TX ESP32 GPIO17 → RX Arduino, TX Arduino → RX ESP32 GPIO16, y GND común.
